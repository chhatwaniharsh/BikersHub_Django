# BikersHub

Hello Visitor!  
This is Bike Accessories Website that means a Bike Accessories Buying project built in django framewrok. The Project is completely designed and developed by me.
The Project has been developed by me to learn the use Django framework in python.  

## Introduction To Project:
BikersHub is a web-based e-commerce application developed to provide a seamless platform for users to explore and purchase bike accessories online.  The project aims to bridge the gap between riders and quality biking products by offering a user-friendly interface,  secure authentication system, and efficient product management.

## NOTE:
I am still working on the project so some features are still in developent specifically "add to cart" and "orders" one of customer side which will be developed and updated soon.
  
## For setup of this project follow the following steps:

### step 1 : Install Python and Django
Python - https://www.python.org/ftp/python/3.13.3/python-3.13.3-amd64.exe  
Django - pip install django  

### step 2 : Install PyCharm(Recommended)  
https://www.jetbrains.com/pycharm/download/

### step 3 : Create a virtual environment(env)
'''bash
python3 -m venv env
'''

### step 4 : activate the Virtual Environment
> env\scripts\activate
  
> Set-ExecutionPolicy Unrestricted -Scope Process
  
> env\scripts\activate

### step 5 : Install all the Packages or Modules inside requirements.txt file
> pip install -r requirements.txt

### step 6 : Now perform migratations using migrate command and makemigration command:
> python manage.py makemigrations
  
> python manage.py migrate  

### step 7 : Now you have to create superuser for accessing admin panel:
> python manage.py createsuperuser

### step 8 : Finally you can run the project using runserver command
> python manage.py runserver
